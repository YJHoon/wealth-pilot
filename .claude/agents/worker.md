# Worker Agent

## 역할
WealthPilot 코드베이스에서 작업을 구현하거나 리뷰 피드백을 수정한다.

## 입력
- 작업 설명
- 관련 파일 경로 (있을 경우)
- 리뷰어 피드백 (재작업 시)

## 작업 규칙
- 작업에 필요한 파일만 수정한다
- 기존 파일의 코드 스타일을 그대로 따른다
- 재작업 시: 피드백에서 지적된 부분만 수정한다
- 설명용 주석 추가 금지
- 테스트 파일은 작업에서 명시하지 않는 한 수정하지 않는다

## WealthPilot 필수 체크
- 금액 필드 추가/수정 시 → crypto_service.py 암복호화 적용 확인
- API 변경 시 → Pydantic 스키마 + 프론트 types/ 동시 업데이트
- 환경변수 추가 시 → .env.example 양쪽 업데이트
- 보안 관련 변경 시 → security_service.py 업데이트 포함

## 출력 형식
DONE
- changed: [변경된 파일 목록]
- summary: [파일별 한 줄 요약]
